Overview

The Title Entry Tool digitizes vehicle title documents by extracting the 14 NMVITIS fields (state, title number, VIN, year, make, model, body style, color, odometer, owner name, owner address, purchase price, sale date, and issue date) from uploaded PDFs or images. Extraction can use OCR (Tesseract), AI (Ollama), or a hybrid of both. After extraction, records are reviewed, corrected, exported as NMVITIS CSV, and optionally used as training data to improve future AI extractions.

Typical workflow: Upload title → Review & correct extracted fields → Enter back-of-title data → Export CSV → (Optional) Mark corrections as ground truth for training.

↑ 1. Uploading a Title Go to Upload page →
  1. Navigate to the Home page (/).
  2. (Optional) Enter a two-letter State override (e.g. NM) if the document's state cannot be detected automatically. Leave blank to let the tool detect it from the title image.
  3. Click Choose File and select a PDF, PNG, JPG, TIFF, BMP, or WebP file (max 16 MB).
  4. (Optional) Check Enter data manually (skip OCR/AI) if you want to type all fields yourself instead of running automated extraction. You will be taken directly to the annotation page after the file is saved.
  5. Click ↑ Extract and Save. The tool will run OCR and/or AI extraction and save a new record to the database.
  6. Review the Extracted Fields and Extraction Details cards that appear. Fields flagged in yellow have low confidence and should be verified.
  7. Click 📋 Records in the navigation bar to open the full record list, or click 🔎 Annotate to go directly to the annotation queue.
AI status indicator: The coloured dot next to AI: in the header shows whether the AI model is ready (green), still loading (yellow pulse), unavailable (red), or not configured (grey). If yellow or red, a warning dialog will appear before submission — you can continue with OCR-only extraction or wait for the AI to finish loading.
📋 2. Review Records List Go to Records →
  1. Click 📋 Records in the navigation bar to open /review.
  2. The table lists all saved records. Each row shows the record ID, state, title number, VIN, year, make/model, validation status, and upload date.
  3. Click ✏ Review on any row to open that record's detail page where you can correct fields.
  4. Click 🔄 Back to open the back-of-title data entry page for that record.
  5. Click ↓ PDF to download a generated NMVITIS PDF for that record.
  6. Export CSV: Use the From and To date pickers to select a date range, then click ↓ Download NMVITIS CSV to export all validated records in that range as a NMVITIS-formatted CSV file.
  7. Use the Previous / Next pager links at the bottom to navigate through multiple pages of records.
✏ 3. Review & Correct a Record
  1. From the Records list, click ✏ Review on a record row to open /review/<id>.
  2. The left panel shows all 14 NMVITIS fields as editable text inputs. Fields highlighted in yellow were extracted with low confidence and need attention.
  3. The right panel displays the original title image so you can visually verify each field value. Use the + / − zoom buttons and click-drag to pan around the image.
  4. Edit any field values that are incorrect or missing.
  5. Click Save Corrections to store your changes without marking them as ground truth.
  6. Click ✓ Mark as Ground Truth to save and flag the current field values as verified — these become training data for the AI.
  7. Click ✓ Approve All & Mark Ground Truth to save and approve all saved corrections for this record at once.
  8. The Correction History panel on the right shows all previous corrections and whether each has been approved as ground truth.
  9. Use ↓ Download PDF to generate and download a NMVITIS PDF for this record.
  10. Use 🔄 Back of Title to navigate to the back-of-title data entry for this record.
Validation: After saving, the record is automatically re-validated. A green Valid badge means all required fields passed format checks. A red badge lists the specific fields that failed validation.
🔄 4. Back of Title
  1. From the Records list or a Review page, click 🔄 Back (or Back of Title) for a record to open /titles/<id>/back.
  2. Upload an image or PDF of the back of the title document using the file chooser, then click Save Back of Title.
  3. Any existing back-of-title image for this record will be replaced.
  4. Click ← Back to Front Review to return to the front-of-title review page for the same record.
🔎 5. Annotation Queue Go to Annotation Queue →
  1. Click 🔎 Annotate in the navigation bar to open /annotate.
  2. Records are sorted so that those with the least ground-truth coverage appear first — focusing your effort where it will benefit AI training the most.
  3. Each row shows the record's current fields, validation status, and how many corrections have been approved as ground truth.
  4. Click ✏ Annotate on any row to open that record's Review & Correct page.
  5. After correcting fields and clicking ✓ Mark as Ground Truth, return to the queue to continue with the next record.
  6. Use the Previous / Next pager links to move through the full queue.
Why annotate? Ground-truth corrections teach the AI model which extractions are correct. The more records you annotate, the more accurate future extractions will be after the next training run.
📥 6. Import NMVITIS Rejections Go to Import Rejections →
  1. From the Records list, click 📥 Import Rejections in the toolbar to open /import-rejections.
  2. Click Choose File and select the NMVITIS rejection file (CSV format) received from the state DMV.
  3. Click Import. The tool will match each rejection entry to an existing record by VIN and/or title number and flag the records that need correction.
  4. Return to the Records list and look for records flagged with rejection errors. Open each one, correct the flagged fields, and re-export the CSV.
🏭 7. Training Dashboard Go to Training →
  1. Click 🏭 Training in the navigation bar to open /training.
  2. The Ground Truth Coverage cards show how many records have been annotated per field. Aim for high coverage across all 14 fields before triggering an export.
  3. The Field Breakdown table shows annotated vs. total record counts for each NMVITIS field.
  4. To prepare a training export:
    1. Optionally enter a Run note in the text box to label this export (e.g. April batch – NM titles).
    2. Click ↓ Export Training Data (ZIP). A ZIP file containing annotated images and labels will be downloaded.
    3. Use the ZIP to fine-tune or retrain your AI model outside this application, then redeploy the updated model via the Diagnostics page.
  5. The Export History table lists all previous training exports with their timestamps and run notes.
Tip: Use ✓ Approve All & Mark Ground Truth on the Review page to batch-approve all saved corrections for a record at once, speeding up dataset preparation.
📊 8. Diagnostics Go to Diagnostics →
  1. Click 📊 Diagnostics in the navigation bar to open /diagnostics.
  2. The AI Status section shows whether the configured AI model is ready, loading, unavailable, or not configured.
  3. If the status is loading, a progress bar shows the model download percentage. The page auto-refreshes every 5 seconds.
  4. The Services section displays the runtime state of all Docker containers (postgres, title-entry-tool, ollama, ollama-init).
  5. Click Start AI Services if the Ollama containers are stopped and you need to enable AI extraction.
  6. Use the per-service View Logs buttons to inspect recent container logs for troubleshooting.
  7. Click ← Back to Title Entry Tool to return to the Home page.
Extraction providers:
  • tesseract – OCR only; AI is not used.
  • ai – AI extraction only (requires Ollama to be running).
  • hybrid (default) – AI results are used where confidence is high; Tesseract fills in the rest.
The active provider is shown in the Mode badge on every page header.
