❓ Help & How-To Guide

Step-by-step instructions for every feature of the NMVITIS Title Entry Tool.

Overview

The Title Entry Tool digitizes vehicle title documents by extracting the 14 NMVITIS fields (state, title number, VIN, year, make, model, body style, color, odometer, owner name, owner address, purchase price, sale date, and issue date) from uploaded PDFs or images. Extraction can use OCR (Tesseract), AI (Ollama), or a hybrid of both. After extraction, records are reviewed, corrected, exported as NMVITIS CSV, and optionally used as training data to improve future AI extractions.

Typical workflow: Upload title → Review & correct extracted fields → Enter back-of-title data → Export CSV → (Optional) Mark corrections as ground truth for training.

↑ 1. Uploading a Title Go to Upload page →
  1. Navigate to the Home page (/).
  2. (Optional) Enter a two-letter State override (e.g. NM) if the document’s state cannot be detected automatically.
  3. Click Choose File and select a PDF, PNG, JPG, TIFF, BMP, or WebP file (max 16 MB).
  4. (Optional) Check Enter data manually (skip OCR/AI) to type all fields yourself instead of running automated extraction.
  5. Click ↑ Extract and Save. The tool runs OCR and/or AI extraction and saves a new record.
  6. Review the Extracted Fields and Extraction Details cards. Fields with low confidence should be verified.
  7. Click 📋 Records in the nav to open the record list, or 🔎 Annotate for the annotation queue.
AI status indicator: The coloured dot in the navigation bar shows whether the AI model is ready (green), downloading (yellow pulse), unavailable (red), or not configured (grey). A warning dialog will appear before submission if yellow or red — you can continue with OCR-only extraction or wait.
📋 2. Review Records List Go to Records →
  1. Click 📋 Records in the navigation bar.
  2. The table lists all saved records. Each row shows ID, state, title number, VIN, year, make/model, validation status, and upload date.
  3. Click ✏ Review on any row to open that record’s detail page.
  4. Click 🔄 Back to open back-of-title entry.
  5. Click ↓ PDF to download a generated NMVITIS PDF.
  6. Use the From / To date pickers then click ↓ Download NMVITIS CSV to export validated records.
  7. Use the Previous / Next pager to navigate pages.
✏ 3. Review & Correct a Record
  1. From the Records list, click ✏ Review.
  2. The left panel shows all 14 NMVITIS fields as editable inputs. Fields highlighted in yellow were extracted with low confidence.
  3. The right panel displays the original title image. Use the + / − zoom buttons and click-drag to pan.
  4. Edit any incorrect or missing field values.
  5. Click Save Corrections to store changes.
  6. Click ✓ Mark as Ground Truth to flag current values as verified training data.
  7. Click ✓ Approve All & Mark Ground Truth to batch approve all saved corrections at once.
  8. The Correction History panel shows all previous corrections and whether each is approved as ground truth.
Validation: After saving, the record is automatically re-validated. A green Valid badge means all required fields passed format checks.
🔄 4. Back of Title
  1. From the Records list or a Review page, click 🔄 Back.
  2. Enter the manual back-of-title data (odometer, buyer name, seller name, sale price, date of sale, notes).
  3. Click Save Back of Title.
  4. Click ← Back to Front Review to return.
⚠ Manual verification required: Seller and buyer signatures must be verified against the physical document before submission to NMVITIS.
🔎 5. Annotation Queue Go to Annotation Queue →
  1. Click 🔎 Annotate in the navigation bar.
  2. Records are sorted with least ground-truth coverage first to maximise AI training benefit.
  3. Click ✏ Annotate on any row to open the review page.
  4. Correct fields and click ✓ Mark as Ground Truth.
  5. Return to the queue to continue with the next record.
Why annotate? Ground-truth corrections teach the AI which extractions are correct. The more records you annotate, the more accurate future extractions will be after the next training run.
📥 6. Import NMVITIS Rejections Go to Import Rejections →
  1. From the Records list, click 📥 Import Rejections.
  2. Select the NMVITIS rejection CSV file.
  3. Click Import to flag records matching the rejections by VIN.
  4. Return to the Records list, correct flagged fields, and re-export.
🏭 7. Training Dashboard Go to Training →
  1. Click 🏭 Training in the nav.
  2. The Coverage charts show annotation progress per field and state.
  3. Enter an optional Run note, then click ↓ Export Training Data (ZIP).
  4. Use the ZIP to fine-tune your AI model outside this application.
  5. Use Apply to AI Model to create a custom Ollama model from your corrections directly — no GPU required.
  6. The Model Management section lets you switch the active model.
Tip: Use ✓ Approve All & Mark Ground Truth on the Review page to batch-approve all saved corrections for a record at once.
📊 8. Diagnostics Go to Diagnostics →
  1. Click 📊 Diagnostics in the nav.
  2. The AI Status section shows whether the model is ready, loading, unavailable, or not configured.
  3. If loading, a progress bar shows download percentage. The page auto-refreshes every 5 seconds.
  4. The Services section shows Docker container state for all Compose services (postgres, title-entry-tool, ollama, ollama-init).
  5. Click Start AI Services if Ollama containers are stopped.
  6. Use per-service View Logs buttons for troubleshooting.
Extraction providers:
  • tesseract – OCR only; AI is not used.
  • ai – AI extraction only (requires Ollama).
  • hybrid (default) – AI results where confidence is high; Tesseract fills in the rest.
